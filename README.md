# dark-monopoles

Python code for the collider phenomenology of dark magnetic monopoles. It computes the LHC
cross section for pp → χχ̄, where χ is a fermionic monopole of a dark U(1) whose dark photon
A′ mixes kinetically with the ordinary photon.

## The model

- **χ:** a fermion carrying dark magnetic charge. The dark photon A′, of mass m_D, couples
  to it like a photon to an electron, with a small dark magnetic coupling g_D.
- **Mixing:** the A′ mixes with the ordinary photon with strength ε.
- **The s-channel,** q q̄ → γ* → A′ → χχ̄, is what this repository computes. Its tree-level
  amplitude vanishes: an electric pair can't produce a magnetic pair through one photon
  with minimal couplings (H.-Y. Lai and J. Terning, arXiv:2608.05272). The leading
  contribution therefore comes from the Pauli form factor F₂ of the monopole vertex,
  generated by a dark-photon loop (eqs. 148–151 of hep-ph/9707496).
- **Photon fusion,** γγ → χχ̄, is allowed at tree level. It's computed separately with a
  modified SFGen and isn't part of this repository. `compare_channels.py` and `reach.py`
  read its results if you have them.

## How the cross section is computed

```
σ(pp → χχ̄) = Σ_q ∫ dτ σ̂(τS) Lum_q(τ)
```

- **`sigma_hat`** in `fermion.py` is the partonic cross section for one quark flavour, with
  the spin sums for the γ5 dipole vertex. It includes the mixing and the A′ propagator, with
  the A′ width computed from the masses and couplings in `dark_photon_width`.
- **`f2_square`** evaluates |F₂|² with mpmath at 80 digits. The individual terms cancel to
  many digits, so double precision gives wrong answers.
- **The integration** is over v = ln τ, with an inner integral over u = ln x₁ for the
  parton luminosity, using LHAPDF PDFs at the scale Q = √ŝ. The narrow A′ resonance gets its
  own integration window of ±30 Γ/m_D in v, so the integrator can't step over it.
- **The A′ width** includes e, μ, τ and hadrons (R × Γ_μμ) through the mixing ε, plus χχ̄
  with α_D = g_D²/4π when m_D > 2m_χ.

## Files

| File | What it does |
|---|---|
| `fermion.py` | The physics: F₂, the partonic cross section, the A′ width, the parton luminosity and the integration. `python fermion.py` prints the cross section for the masses and couplings at the bottom of the file. |
| `2D_scan.py` | Scans the s-channel cross section over m_D and m_χ, saves it to `results/` and plots a heat map. |
| `k_cut_scan.py` | The same scan, keeping only √ŝ ≥ K_CUT·m_D (see Limitations). |
| `dark_photon.py` | Upper limits on ε digitized from published figures, mainly for an invisibly decaying A′. `epsilon_max(mass)` returns the strongest one. `python dark_photon.py` plots them. |
| `reach.py` | Rescales saved scans to the largest allowed ε and finds the heaviest m_χ that gives at least one produced pair, at Run 3 and HL-LHC luminosities. |
| `compare_channels.py` | Compares the s-channel scan with a photon-fusion scan on the same grid. |
| `plot_scan.py` | Draws a heat map from any saved scan without recomputing it. |
| `scan_F.py` | Heat map of \|F₂\|² against β and ℓ = λ²/M². |
| `check_m_growth.py` | \|F₂\|² against the monopole mass, compared with M⁴. |
| `scalar.py` | An earlier version of the calculation, for scalar monopoles. |

Each script has a block of adjustable parameters near the top, marked
`# ===== Parameters you can adjust =====`.

## Setup

Tested with Python 3.12 on macOS.

1. **Python packages:** numpy, scipy, mpmath and matplotlib.
2. **LHAPDF 6** with its Python bindings, installed into the same environment. This was
   developed with 6.5.6, built from source into `.venv`.
3. **The PDF set** `NNPDF31_lo_as_0118` (set in `fermion.py`):
   ```bash
   .venv/bin/lhapdf install NNPDF31_lo_as_0118
   ```

## Usage

Run every script from the repository root.

```bash
.venv/bin/python fermion.py        # one point
.venv/bin/python 2D_scan.py        # scan, saved to results/ and plotted
.venv/bin/python k_cut_scan.py     # scan with the sqrt(s_hat) >= K_CUT * m_D cut
.venv/bin/python plot_scan.py      # redraw a saved scan
```

- **Scan files:** `results/s_channel_<energy>TeV_eps<ε>_gD<g_D>_<N_m_D>x<N_m_χ>.csv`, one row
  `m_D_GeV, m_chi_GeV, sigma_pb` per point, with the settings in the header. An existing
  file is never overwritten.
- **Loading a scan:**
  ```python
  m_D, m_chi, sigma = np.loadtxt(path, delimiter=",", unpack=True)
  ```
- **Not in git:** `results/` is ignored, so scans live only where you run them.
- **Rescaling with ε:** the s-channel cross section scales as ε². On the resonance it also
  depends on the A′ branching ratio to χχ̄; `reach.py` accounts for that.

## Conventions

- **Energy and units:** √S = 13.6 TeV by default. Cross sections are in pb, masses in GeV,
  with 1 GeV⁻² = 3.894 × 10⁸ pb.
- **Constants:**
  - α = 1/137, used both in σ̂ and in the A′ width.
  - R = 1 for the hadronic width, an order-of-magnitude choice.
  - Quark masses as listed in `QUARKS` in `fermion.py`.
- **Couplings:** `EPS` is the kinetic mixing ε; `G_D` is the dark magnetic coupling g_D.
- **Notation:** the dark photon mass is m_D in the code (`M_D`); some plots label it m_A′.
- **Digitized limits:** good to about 2–5% in ε and 1% in mass. Use the original papers
  for anything precise.

## Limitations

- **Confinement.** A massive dark photon confines the monopoles: the Dirac string becomes a
  flux tube of length about 1/m_D. The free-pair calculation gives the right total only
  when the pair is produced at √ŝ ≫ m_D. Near √ŝ ≈ m_D, including the A′ resonance, and below
  it, the χχ̄ pair is bound from the start and the result should not be trusted.
  `k_cut_scan.py` keeps only the region where the calculation applies.
- **Only produced events.** There are no detector effects, cuts or backgrounds. The χχ̄
  pair is treated as invisible.
- **The coupling on the resonance.** Production uses the loop-level F₂ vertex, while the
  A′ → χχ̄ width uses a tree-level coupling. Whether these are consistent on the resonance
  is an open question.
- **The digitized limits are incomplete:**
  - visibly decaying dark photons are only covered from 3 to 68 GeV;
  - the electroweak precision bound stops at 284 GeV;
  - the dilepton curves have gaps at the J/ψ, ψ(2S) and ϒ masses.
